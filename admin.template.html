사용법 — 처음이시면 눌러 보세요

1. 이 화면을 휴대폰 첫 화면에 두기

  • 아이폰: 아래 가운데 [공유] → [홈 화면에 추가]
  • 갤럭시: 오른쪽 위 [⋮] → [홈 화면에 추가]
  • 비밀번호는 이 기기에서 한 번만 넣으면 됩니다.

2. 첫 화면 사진·제목 바꾸기

  1. [첫 화면·공지] → [큰 사진 바꾸기] → 사진 고르기. 가로 사진이 좋습니다.
  2. 제목은 두 줄까지, 한 줄 소개는 두세 문장.
  3. 아래 [저장] → 1~2분 뒤 홈페이지에 바뀝니다.

3. 공지 켜고 끄기

  • 문구를 적고 [홈페이지에 보이기]를 켜면 첫 화면 제목 위에 나옵니다. 끄면 문구는 남고 화면에서만 사라집니다.

4. 새 글 쓰기

  1. [소식·블로그] → [+ 새 글 쓰기]
  2. 제목: 지역 + 무엇 (예: 청풍호 독채 펜션, 겨울 온실은 춥지 않나요?)
  3. 요약: 이 글의 답을 한두 문장으로. 검색 결과에 그대로 보입니다.
  4. 본문: [소제목]은 질문으로, 바로 아래 첫 문장에 답을 적으세요.
  5. [저장] → 1~2분 뒤 홈페이지 소식에 올라갑니다.

5. 쓴 글 고치기

  • 글 목록에서 글을 누르거나, 홈페이지에서 글을 보다가 오른쪽 아래 「이 글 수정」을 누르세요. (이 기기에서 들어와 있을 때만 보입니다)

6. 사진

  • 넣기: 넣을 자리를 한 번 누르고 → [사진 넣기]. 여러 장 한 번에 됩니다. 크기는 자동으로 줄어듭니다.
  • 빼기: 사진을 눌러 빨간 테두리가 생기면 → [고른 사진 빼기]

7. 검색에 잘 걸리는 요령

  • 숫자로 쓰기 — 요금, 시간, 인원, 거리
  • 실제 사진 쓰기, 지어낸 후기 쓰지 않기
  • 글 하나에 주제 하나. 전화·입퇴실 시간은 글에 따로 적지 말고 [연락처·요금]에서 고치세요. 그래야 홈페이지 전체가 같은 값이 됩니다.

8. 실수했을 때 · 안 될 때

  • 저장 전이면 [목록]으로 나가거나 새로고침하면 바뀐 것이 버려집니다.
  • 「저장 실패」: 인터넷을 확인하고 [저장]을 다시 누르세요.
  • 저장했는데 안 바뀜: 1~2분 기다린 뒤 홈페이지를 새로고침(휴대폰은 아래로 당기기). [반영 진행 보기]에서 초록 표시가 뜨면 끝난 것입니다.
  • 비밀번호가 안 맞음: 관리하는 분께 새 비밀번호를 받으세요.

9. 비밀번호 관리 (관리하는 분)

  • 비밀번호는 카톡 단체방에 올리지 마세요.
  • 직원이 그만두면 [비밀번호 정하기·바꾸기]로 바꾸세요. 그러면 모든 사람이 새 비밀번호를 넣어야 합니다.
  • 바꿀 때는 이 홈페이지 전용 GitHub 토큰이 한 번 필요합니다. 모르시면 만든 곳에 문의하세요.
